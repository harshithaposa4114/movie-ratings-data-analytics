# Movie Ratings and Genre Analysis

## Objective
Explore fictional movie ratings, genre averages, release-year trends, and popularity.

## Tools
Python, Pandas, Matplotlib. SQL queries are included for practice.

## Run
1. Install Python 3.
2. Open terminal in this folder.
3. Run `pip install pandas matplotlib`
4. Run `python analysis.py`

## Questions
- Which genre has the highest average rating?
- Which movies have the most votes?
- How many movies were released each year?
